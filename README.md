# Whisky Universal Downloader

نسخة أولية لبوت Telegram يستخدم yt-dlp لمحاولة تنزيل وسائط من روابط مدعومة.

## التشغيل
1. أنشئ ملف `.env` محليًا وضع فيه `TELEGRAM_BOT_TOKEN`.
2. ثبّت المتطلبات: `pip install -r requirements.txt`
3. شغّل: `python bot.py`

الدعم الفعلي للمواقع والنشر المستمر غير مُتحقق منه. استخدم البوت فقط مع المحتوى الذي تملك حق تنزيله.
